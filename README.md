# Отчёты: фото → Telegram и Яндекс Форма

Веб-приложение на Mac, которое открывается с телефона. Вы загружаете фото и отмечаете пункты формы прямо на экране. Разделы там те же, что в Яндекс Форме: термосумка, велосипед, КИСАРТ, АТК, форма ULTIMA, номер на ТС и отказ от помощи. Номер сумки и сервис можно вписать самому, а если оставить их пустыми, они определятся по фото. Пункты про термосумку и номер на ТС видны только для Еды, потому что для Лавки их в форме нет. Список пунктов лежит в `photoapp/rules/form_items.json`. Короткие слова в комментарии («наклейки», «грязная») тоже по-прежнему отмечают пункты. Дальше приложение всё делает само:

1. Распознаёт на фото номер сумки, телефон и ID (Apple Vision, запасной вариант Tesseract).
2. Определяет сервис: сумки `AA`, `AB`, `TA` — Лавка, остальные — Еда.
3. Публикует фото с подписью в канал Telegram.
4. Заполняет форму в браузере без окон, отмечает пункты, прикрепляет фото и нажимает «Отправить».

## Когда форма не отправляется сама

Форму нельзя отозвать, а её обязательные поля не требуют ни нарушения, ни фото. Поэтому отчёт получает статус «Нужна проверка», если:

- номер сумки не найден;
- не отмечен ни один пункт, или пункт не нашёлся в форме;
- фото не прикрепились к форме;
- какое-то поле не заполнилось.

В карточке отчёта можно поправить номер, сервис, пункты и комментарий и нажать «Отправить». Без номера сумки форма не отправится никогда, он обязателен в самой форме.

Автоматически отправка не повторяется. Если приложение перезапустилось во время отправки или форма не подтвердила её, отчёт ждёт решения человека. Те же фото второй раз не обрабатываются.

## Установка

Нужны Tesseract с русским языком (`brew install tesseract tesseract-lang`) и Python 3.9 или новее.

```bash
python3 -m venv .venv
```

```bash
.venv/bin/pip install -r requirements.txt
```

```bash
.venv/bin/playwright install chromium
```

```bash
cp .env.example .env
```

Заполните `.env`. Ключ `APP_KEY` можно придумать любой длинный или получить так:

```bash
.venv/bin/python -c "import secrets; print(secrets.token_urlsafe(24))"
```

## Запуск

Двойной щелчок по `start.command`. Mac не засыпает, пока приложение работает, а при сбое оно перезапускается. Страница: `http://адрес-mac:8765/?key=APP_KEY`, ключ нужен один раз на устройство.

`AUTO_SUBMIT=0` в `.env` выключает авто-отправку: форма заполняется и проверяется, а отправляет её кнопка в приложении.

## Доступ с улицы

Приложение работает на Mac, поэтому телефон должен до него достать. Вне домашней сети для этого подойдёт бесплатный [Tailscale](https://tailscale.com/download): поставьте его на Mac и телефон под одним аккаунтом и открывайте страницу по адресу Mac в Tailscale (`100.x.x.x`). Mac должен быть включён и в сети.

## Правила

Правила лежат в `photoapp/rules/`:

- `fields.json` — что и как искать на фото;
- `shortcuts.json` — какие слова отмечают какие пункты формы;
- `marks.json` — необязательные пункты для конкретных сумок, в git не попадает: `{"PY0000": ["Сумка утратила внешний вид"]}`.

Ссылка на форму и номер велопомощника хранятся только в `.env`.

## Откуда код

`extractor.py`, `form_filler.py` и правила скопированы из `Luntiqueil/telegram-photo-bot` (коммит `d9d5689`). Отличия `form_filler.py`:

- браузер работает без окон и без порта отладки;
- адрес формы и велопомощник берутся только из `.env`;
- правила лежат в `photoapp/rules/`, добавлен `close_browser()`.

Бот и приложение могут работать одновременно: приложение только публикует сообщения и не читает обновления Telegram.
